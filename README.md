## Compatibility

RusTTY has been tested, survived, and confirmed working on:

- Windows 11
- Windows 10
- Windows 8.1 *(Yes, really.)*
- Windows Server 2022
- Windows Server 2016
- Windows Server 2012 R2 *(Still alive... somehow.)*

## Minimum Requirements

RusTTY was designed to be lightweight. Your old 2014 server should be fine. If it can still boot, it can probably run RusTTY.

| Component | Requirement |
|-----------|-------------|
| CPU | 2 vCPU @ 1.5GHz (amd64) — or a reasonably fast potato |
| Memory | 128MB RAM — unlike your browser, we don't hoard it |
| Graphics | Intel HD Graphics 4000 — if it can draw pixels, it works |
| Storage | 25MB — fewer megabytes than a single `node_modules` folder |
| Operating System | Windows Server 2012 R2 or newer |

## Recommended Requirements

If you like luxury and running things smoothly:

| Component | Requirement |
|-----------|-------------|
| CPU | 4 vCPU @ 2GHz or better |
| Memory | 512MB RAM |
| Graphics | Any dedicated GPU released within the last decade |
| Storage | 100MB available space |
| Operating System | Windows 10 or newer |
| Network | Anything better than dial-up |

> **Note:** A stable network connection is highly recommended.  
> RusTTY is powerful, but it still can't fix packet loss caused by a dog-chewed Ethernet cable... *yet*. 

## Supported Protocols

What works right now (and what's on the roadmap):

- SSH ✅
- Telnet ⏳ *(Because legacy infrastructure never dies, it just haunts us)*
- Serial ⏳ *(Planned)*
- FTP ⏳ *(Planned)*
- SFTP ⏳ *(Planned)*

> Yes, Telnet is still alive. Somewhere in a server room, protected by dust, cobwebs, and the fear of whoever is responsible for that... *thing*.
